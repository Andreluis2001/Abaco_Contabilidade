# Ábaco Contabilidade - Controle de Patrimônios Eletrônicos

Este projeto é um sistema para controle e gestão de patrimônios eletrônicos de um escritório de contabilidade. Permite o cadastro, acompanhamento e manutenção de equipamentos eletrônicos, proporcionando maior organização e rastreabilidade dos ativos. O sistema foi desenvolvido visando segurança, escalabilidade e facilidade de uso para os colaboradores do escritório.

## Tecnologias Utilizadas

- **Backend:** Django
- **Frontend:** React.js, TypeScript
- **Banco de Dados:** PostgreSQL
- **Autenticação:** JWT (JSON Web Token)
- **Containerização:** Docker
