# Abaco_Contabilidade

Sistema de controle patrimonial do escritório de contabilidade Ábaco Contabilidade

-----------------------------------------------------------------------------------

Instruções para rodar frontend, backend e banco de dados:

-----------------------------------------------------------------------------------

!!! Você talvez precisará habilitar o WSL no seu Windows !!! 

-----------------------------------------------------------------------------------

1 - Você precisa ter docker instalado (link para instalação: https://docs.docker.com/desktop/setup/install/windows-install/):

![Screenshot 2025-06-08 153620](https://github.com/user-attachments/assets/e13a472e-3b25-4fc6-9795-54e00a7e82fc)

A instalação é bem simples.

2 - No VSCode clique com o botão DIREITO do mouse na pasta Abaco_contabilidade e clique na quarta opção do menu que abrir:

![Screenshot 2025-06-08 154322](https://github.com/user-attachments/assets/9c19c0d6-47fe-4ab6-8298-0ef68b9dda15)

3 - Um terminal vai abrir (tenha certeza que o caminho da pasta está correto):

![Screenshot 2025-06-08 163056](https://github.com/user-attachments/assets/d8e39c55-9e56-4e74-b28b-a51c34c6dcd9)

4 - Escreva esse comando e aperte enter:

![Screenshot 2025-06-08 163224](https://github.com/user-attachments/assets/617022a7-d90a-4c70-b08a-13b8742104a4)

5 - Espere alguns segundos, abra seu navegador e escreva http://localhost:5174/ na barra de busca. A página de login deve abrir, se tudo estiver dado certo, o unico usuário que temos por enquanto é
